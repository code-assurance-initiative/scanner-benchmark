# Pilot 2026-10: three engines on the public training set

> ## This is a pilot. It qualifies no engine.
>
> It rehearses the qualification procedure of
> [ENGINE-QUALIFICATION.md](https://github.com/code-assurance-initiative/CodeAssuranceIndex/blob/main/docs/ENGINE-QUALIFICATION.md)
> on the **public** training set, so the figures are **in-sample** and not comparable as a ranking:
>
> - **The CAI reference implementation was calibrated on exactly these C# units** (see
>   [results/cai-reference/COMPARISON-TRAINING.md](results/cai-reference/COMPARISON-TRAINING.md)); its figures measure
>   fit to these answer keys as much as detection.
> - **Watchdog's row is its frozen iteration-1 baseline** (taken before any improvement work), and Watchdog was the
>   instrument used while the units were authored ([results/watchdog/README.md](results/watchdog/README.md)).
> - **Semgrep ran with its default community rules** (`p/default`), which cover security only; most of what the
>   benchmark measures (code health, architecture, tests, maturity, accessibility) is outside what those rules look for,
>   so its overall recall mostly measures scope, not quality. Its mapping was written by the pilot operator.
>
> The honest comparison is the sealed holdout in the first challenge window
> ([challenge/calendar.json](challenge/calendar.json)), which no engine has seen.

## What was run

- **watchdog**: Watchdog, kennel main 6a05dfb6c, rubric-2026.10.1; contained scans (codehealth-analyzer:train-src-89d1e8def87553cc)
- **cai-reference**: CAI reference implementation (cai-reference 0.1.0), reference-implementation d3c2e24, Release build, rubric-2026.10.2; default configuration (no --nuget-packages)
- **semgrep**: Semgrep CE 1.179.0 (docker semgrep/semgrep@sha256:93963d9295a366f59e4850127b1550400ee7b388f04fe144e4a1f6325d96e01b), semgrep scan --config p/default --metrics=off --sarif; default configuration

All three were scored with `cai_bench` 1.5.0 (contract 1.6). Per-unit results are under `results/<engine>/`.
**SonarQube** was planned but not run in this pilot; whether SonarSource's terms permit publishing comparative results
has not yet been checked, and nothing about it is published here.

## What the pilot showed about the procedure

- Running three very different engines through one harness works: SARIF in, one mapping per engine, one scorer.
- The mapping is where judgment enters; for engines that ship none, the operator writes it. In a real window the
  engine's maker submits it, hashed, before the holdout opens.
- Scope must be visible next to recall: an engine that measures only security should not be read as poor at code
  health. The qualification record therefore reports per dimension and states coverage.
